Algorithms of the City VII · Spatial Optimisation

VII · Spatial Optimisation

Given a parcel of land, a programme of uses, and a single entrance from the street — where should each use be placed to minimise the total cost of movement within the building and from every space to the door?

VII.1

Optimal Placement on a Three-Storey Parcel

Hill-climbing search over a 5 × 15 × 3 grid, minimising weighted travel cost.

A parcel is 5 metres wide and 15 metres deep, with three floors — 225 tiles in total. An entrance opens from a street on one edge of the ground floor. A single staircase connects all floors; its position is itself part of the optimisation. We must place N programmatic tiles somewhere on this parcel so that the total cost of movement is minimised.

Two costs are balanced. Accessibility: how far, in aggregate, is every occupied tile from the entrance? A tile far from the door is hard to reach — it serves fewer people, generates more effort. Connectivity: how far is every tile from every other? A compact programme is efficient to navigate; a dispersed one wastes time between activities.

Vertical travel is routed exclusively through the staircase tile. To move between floors, a person walks horizontally to the staircase, climbs (each floor costs a configurable number of equivalent metres), then walks from the staircase to their destination. Upper floors require structural support: the tile directly below must be occupied. These constraints — the cost of verticality, the mandatory staircase route, and the stacking requirement — make upper floors a last resort, used only when horizontal clustering on the ground plane no longer improves the score.

The optimiser uses hill climbing. At each step it either tries a random tile swap or a staircase relocation, accepting only moves that reduce the total score. The two objectives are balanced by a single slider scaled so that, at the midpoint, each term contributes equally regardless of programme size.

// Staircase-routed distance (metres)
function dist(a, b, stair):
  if a.floor == b.floor:
    return |a.r-b.r| + |a.c-b.c|
  return |a.r-s.r| + |a.c-s.c|       // walk to stair
       + |a.floor-b.floor| × VERT         // climb
       + |b.r-s.r| + |b.c-s.c|       // walk from stair

// Score: (N−1) balances entrance sum against pairwise count
function score(tiles, entrance, stair):
  s1 = Σ dist(t, entrance)         // accessibility
  s2 = Σ dist(t_i, t_j) for i<j   // connectivity
  return w1×(N-1)×s1 + w2×s2

// Hill-climbing: tile swaps (70%) + staircase moves (30%)
repeat:
  if random() < 0.3: tryStairMove(stair)
  else:
    R = random occupied tile with no tile stacked above
    A = random empty tile whose floor-below is occupied (or ground)
    if score(swap R→A) < score(current): apply swap
