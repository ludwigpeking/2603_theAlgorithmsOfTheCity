# The Algorithms of the City

## The project

This is an online/open book that is to:
1. Reveal the mechanisms behind the self-organization of cities, a notion that is on the opposite of the top-down planning of the city, acknowledging the role of bottom-up processes in shaping the city.
2. Help learners, designers, and planners to get exposures of the layers of algorithms. improving their understanding of the city and their respects on the spantenous order in the city, a type of containers of humanity.
3. provide a platform for a library of running urban simulations that can be reused in other applications.

This project started in March 2026, but the ideas were conceived in the previous work of Richard Qian Li, [The Evolutionary History of the City](https://the-book-an-evolutionary-history-of-the-city.vercel.app/?chapter=0&lang=en)

## The author(original)

Richard Qian Li is an archiect, urban designer and software developer, with background in real estate development, software engineering, and interactive media. Richard is also a content creator on Ximalaya, TicTok, and Youtube.

## Structure of the book

The book is sturctured with multiple chapters, the order of which is intended to be arranged by scale, from larger to smaller.

It is not strictly necessary to read the chapters in order, as each chapter is designed to be self-contained and can be read independently and the algorithms are intrinsicly a net, a linear order is never fully reflecting the nature of the algorithms. 

So there's no specific of order to read them.

## The contents of the chapters

1. Description of the algorithm
2. Illustrations
3. Pseudocode
4. Simulations/playgounds for the algorithm, to test with different parameters and settings
5. Code download links
