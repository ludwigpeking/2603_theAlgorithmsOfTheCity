Algorithms of the City IV · Spatial Syntax

IV · Spatial Syntax

"The city is not a tree... it is a semi-lattice."
— Christopher Alexander

Space is not experienced in straight lines. Every traveller navigates a landscape of friction — hills, rivers, mud, cliffs — that distorts the geometry of distance into the topology of cost. Accessibility, the true measure of urban proximity, is not how far away a place is but how costly it is to reach.

IV.1

Isochrone Accessibility

The set of all places reachable within a given travel cost — terrain-aware, mode-dependent.

An isochrone is the boundary of everything reachable from a point within a given budget of effort. On flat pavement it is a circle; on terrain it folds and stretches — squeezed by mountains, pulled along valleys, interrupted by water. Where many isochrones overlap, accessibility accumulates: these are the natural centres of a region, the places that gravity has always drawn settlement toward.

The shape of an isochrone reveals a mode's personality. A pedestrian's isochrone is large and lumpy — she can scramble over ridges that stop a cart cold. A vehicular isochrone is flatter and more elongated: carts can cover far more ground on level valley floors, but steep slopes and river crossings cut them off entirely. The same point in the landscape offers a completely different world depending on how you move through it.

Three cost tiers are shown simultaneously. Each tier adds the new territory opened up as the travel budget grows. The innermost ring (red) is what you can reach with minimal effort — your immediate neighbourhood. The middle ring (ochre) is the wider district. The outer ring (blue) is the regional horizon — everything that is technically reachable but demands real commitment to traverse.

The term space syntax and its analytical framework were coined by Bill Hillier and Julienne Hanson at University College London (UCL) in the 1970s–80s, developed in their foundational work The Social Logic of Space (Cambridge, 1984). The UCL Space Syntax Laboratory continues this research today. The simulation here draws on that tradition — using terrain-weighted travel cost as the measure of spatial integration rather than the topological graph metrics of the original theory. 

// Full-map Dijkstra: cost from one source to all tiles
function dijkstraFrom(start, mode):
  dist[all tiles] = ∞
  dist[start]     = 0
  frontier = priority_queue {(0, start)}

  while frontier not empty:
    (cost_so_far, current) = frontier.pop_min()
    if cost_so_far > dist[current]: skip   // stale entry

    for each neighbour of current:
      edge = terrainCost(current, neighbour, mode)
      new_cost = dist[current] + edge
      if new_cost < dist[neighbour]:
        dist[neighbour] = new_cost
        frontier.push(new_cost, neighbour)

  return dist   // dist[i] = min travel cost from start to tile i

// Classify into three tiers
tier_1 = { i : dist[i] ≤ 20  }   // immediate reach  (~4 km flat equivalent)
tier_2 = { i : dist[i] ≤ 80  }   // neighbourhood    (~15 km flat equivalent)
tier_3 = { i : dist[i] ≤ 320 }   // regional reach   (~60 km flat equivalent)
